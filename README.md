# NowK

Programming IDE with browser profiles. Chạy trên macOS, Windows và Linux.

## Install

```bash
npm i -g nowk-ide
nowk start
```

Lần cài đầu sẽ tải Electron. Nếu GPU Linux lỗi, chạy:

```bash
NOWK_DISABLE_GPU=1 nowk start
```

## Local

```bash
npm install
npm run build:ui
npx nowk start
```
